# Jannik Reinbold Academic Website

This is a minimal static academic website for GitHub Pages. It has no build
step and uses only `index.html`, `styles.css`, and `cv.pdf`.

## Files

- `index.html`: the website content.
- `styles.css`: the simple responsive design.
- `cv.pdf`: placeholder CV file. Replace it with the real CV, keeping the same
  filename so the "Curriculum Vitae" link continues to work.

## Publish On GitHub Pages

1. Create a GitHub repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload `index.html`, `styles.css`, and `cv.pdf` to the repository root.
3. Commit the files to the default branch.
4. Visit `https://YOUR-GITHUB-USERNAME.github.io` after GitHub Pages finishes
   publishing.

For a project repository instead of a `username.github.io` repository, enable
GitHub Pages in the repository settings and publish from the default branch.

## Edit The Placeholders

- Replace the intro paragraph with your affiliation and research interests.
- Replace the Google Scholar `href="#"` in `index.html` with your profile URL.
- Replace the placeholder paper and project titles/descriptions with your own.
- Replace `cv.pdf` with your real CV PDF.
